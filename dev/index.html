TinyMCE Paste from Word — Integration Test

Copy content from Microsoft Word and paste it into the editor. Lists, tables, styles and images (Chrome, Edge and Safari provide the RTF clipboard) are cleaned by the plugin. Use the toggle button in the toolbar to force the cleanup for any pasted HTML.

Events



  
Clean raw HTML

  

    Paste the raw Word HTML (for example from a saved fixture) and clean it with the API of the plugin:
    editor.plugins.pastefromword.cleanWord(html).
